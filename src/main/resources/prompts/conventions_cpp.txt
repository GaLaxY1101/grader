- File name: test.cpp, compiled with `g++ -std=c++17 -DGRADER_MAIN test.cpp` and run.
- First line: `#include "grader_test.h"` (the grader's test harness; it provides `main()`).
- Then include the standard headers you need and the solution with `#include "{{solutionFile}}"`.
- Each test case is `TEST_CASE(test_<name>) { ... }`. Do not write `main()` and do not print PASS/FAIL lines.
- Check results with `EXPECT_EQ(expected, actual)`, `EXPECT_TRUE(condition)`, `EXPECT_FALSE(condition)`
  or `EXPECT_NEAR(expected, actual, eps)` for floating point. The expected value comes first.
- Wrap brace-initialized expected values in parentheses, e.g. `EXPECT_EQ((std::vector<int>{1, 2}), actual)`.

Example:
```cpp
#include "grader_test.h"
#include <string>
#include <vector>
#include "{{solutionFile}}"

TEST_CASE(test_two_positive_numbers) {
    EXPECT_EQ(5, add(2, 3));
}

TEST_CASE(test_negative_numbers) {
    int actual = add(-2, -3);
    EXPECT_EQ(-5, actual);
}
```
